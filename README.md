## Como funciona

O site é uma página estática feita em HTML. O Bootstrap organiza o layout responsivo, enquanto o arquivo `style.css` define a aparência, as cores e os tamanhos dos elementos. O menu superior usa links internos para navegar entre as seções.

## Recursos novos

### Alternância entre modo escuro e modo claro

O botão no menu alterna entre os dois temas. As cores de cada tema são definidas por variáveis CSS, e o JavaScript altera o atributo `data-theme` do elemento `<body>`. A escolha fica salva no navegador com `localStorage`, mantendo o tema selecionado na próxima visita.

### Reorganização das fotos por arraste

As fotos em formato de octógono podem ser arrastadas para trocar de posição. O JavaScript usa eventos de ponteiro (`pointerdown` e `pointerup`) para detectar o arraste e reorganizar os elementos no HTML. O recurso funciona com mouse e telas sensíveis ao toque.
